PANDUAN PENGGUNAAN OFFLINE (HP ANDROID / IOS)

Aplikasi ini telah disiapkan untuk berjalan secara offline. Ada dua cara penggunaan:

CARA 1: COPY FILE (KHUSUS ANDROID)
1. Salin seluruh folder 'pwa_dist' ke penyimpanan HP Android Anda.
2. Buka File Manager di HP, cari file 'index.html' di dalam folder tersebut.
3. Buka dengan browser Chrome.
4. Aplikasi akan berjalan tanpa internet.

CARA 2: PWA / WEB APP (ANDROID & IOS - DISARANKAN)
1. Upload isi folder 'pwa_dist' ke hosting gratis (seperti GitHub Pages atau Netlify).
2. Buka link website Anda di browser HP (Chrome/Safari).
3. Klik menu browser -> "Add to Home Screen" (Tambahkan ke Layar Utama).
4. Aplikasi akan terinstall seperti aplikasi native dan bisa dibuka offline kapan saja.

CATATAN:
- Untuk iOS, Cara 2 adalah satu-satunya cara agar aplikasi berjalan sempurna fullscreen.
- Fitur AI (Gemini) tetap membutuhkan koneksi internet. Fitur hitung manual tetap jalan 100% offline.
